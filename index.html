О проекте

«ABC Explorer» — интерактивная игра для изучения английского алфавита в начальной школе.

🎯 Цель

Сформировать устойчивое узнавание букв английского алфавита, их заглавного и строчного начертания, а также первых английских слов в игровой форме.

👩‍🏫 Для учителя

7 режимов: изучение алфавита, прописи, узнавание букв, аудирование, составление слов, алфавитный порядок и «пары». Подходит для разминки, индивидуальной работы и интерактивной доски.

🧠 Что тренируется

Зрительная память, фонематический слух, мелкая моторика, внимание и навык соотнесения буквы со звуком и словом.

⚙️ Технологии

HTML5, CSS3, JavaScript (ES6), Web Speech API (озвучка), Web Audio API (звуки), Canvas (прописи), localStorage (прогресс). Без сторонних библиотек.

Прогресс сохраняется в браузере на этом устройстве. Озвучка работает, если в системе установлен английский голос.
